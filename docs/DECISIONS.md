# 设计决定记录

按时间顺序记下几个真正影响结构的判断。每条写清楚：当时的约束、选了什么、放弃了什么、代价是什么。被否掉的方案比选中的方案更能说明这个项目的位置。

---

## 1. 只做一元多项式，不做多变量 CAS

**背景**：命题需要符号计算，而 MoonBit 生态里已经有 `maxima` 的移植和 `symbit` 这样的完整符号栈。

**决定**：自己做一元、有理系数的多项式，够用为止。判定与求根只覆盖到二次。

**放弃**：多变量、根式、三角恒等变换、不等式解集。

**代价**：题族受限。但换来两件事——判定可完备（一元多项式的同解等价是能算准的），以及零依赖（不用背 CAS 的许可证与体积）。

---

## 2. 生成器与验证器走完全不同的推导路径

**背景**：所有生成式系统都会遇到同一个问题——如果「生成」和「检查」共用代码，一个符号错误会在两边同时出现并互相抵消，看起来一切正常。

**决定**：生成侧从答案出发用韦达定理反解系数；验证侧从系数出发算判别式、开方、套求根公式，再比对解集。两条路径除了判别式的定义不共享任何代码。

**放弃**：复用生成器里的中间结果（那样更快，也更省事）。

**代价**：重复实现一遍数学，代码量大约多三成。换来的是 `moon test` 可以当作全题库体检用——这条是项目的立足点，不能省。

---

## 3. 结构指纹按「同解」而不是「同系数」判定

**背景**：`2x²-10x+12=0`、`x²-5x+6=0`、`-x²+5x-6=0` 是同一个方程，学生一眼能看出来。按系数去重会把它们当成三道题。

**决定**：清分母 → 约去公因子 → 首项取正，得到的整数向量作为指纹。对一元多项式，这个映射既 sound 又 complete。

**放弃**：保留系数原样（会撞题），或者按根集合去重（要解方程，且对高次不稳定）。

**代价**：一个重要推论——整数根的一元二次方程里，`a>1` 必然与 `a=1` 同解，所以 schema 里把 `a` 固定成 1。这不是偷懒，是让 schema 与指纹的语义保持一致。反过来，分式方程的指纹不能只取去分母后的式子：`(x-8)/(x-4)=2` 和 `(x-12)/(x-4)=3` 同解但长得不一样，所以分式族把可见的分子、分母、右端一起纳入指纹。

---

## 4. 适定性：两条硬门槛，一条软信号

**背景**：Hadamard 的三条件（存在、唯一、稳定）听起来都该是硬门槛。但「稳定」在整数题目里很难定义得不苛刻。

**决定**：
- **存在**与**唯一**是硬门槛，不通过直接丢弃；
- **稳定**降级为软信号：把系数各自 ±1 扰动，看是否仍是两个相异实根。不稳的题照常收录，只是组卷时排在后面。

**放弃**：把稳定性也做成硬门槛（会把判别式小的正常题全部误杀），或者干脆不做（那「适定性」就只剩一半）。

**代价**：需要向使用者解释「robust=false 不是错题」。答案页里如实标注。

---

## 5. 去重账本用纯文本，不用数据库

**背景**：老师按周出卷，这周发过的题下周不能再出现。第一反应是上 SQLite。

**决定**：一行一个指纹的纯文本文件，`--exclude` 读、`--record` 写。

**放弃**：数据库（多一个依赖、多一套迁移）、JSON（diff 不友好）。

**代价**：没有索引，几千条之后线性扫描。但这个量级下无关紧要，而可 diff、可手改、可进版本库的好处是立刻能感受到的。

---

## 6. 组卷用确定性贪心 + 显式缺口，不做完备搜索

**背景**：难度配额 + 结构多样性 + 已选排除叠在一起，本质是多维背包，NP-hard。

**决定**：单遍贪心，受约束的先取；取不满就返回**具体缺口**，不返回残卷。

**放弃**：回溯搜索（能保证有解时找到解，但最坏情况时间不可控），或者静默降级（对使用者最不友好的一种「聪明」）。

**代价**：存在「有解但贪心没找到」的情况。这一点写在 README 的边界里，不装作完备。真正的解法是把组卷建模成整数规划，那是下一步的事。

## 附：开发中被测试抓到的三个真 bug

记在这里，因为它们是这套测试结构的价值证明，不是花絮。

1. **同卷重题**：按难度分档抽取时，每一档都重新洗牌，跨轮次没有记录已选集合。跨 10 个种子的扫描抓到的。
2. **退化题霸屏**：10 道题里 4 道常数项为 0。原因不是随机性，而是这些题全被判成最低难度，低难度档被它们占满。修法是给结构打标签并设配额。
3. **`a>1` 全是重复**：见第 3 条。指纹按同解合并之后，`a∈{1,2,3}` 的三个实例被正确判为同一道题，于是 schema 里的枚举范围失去意义。
