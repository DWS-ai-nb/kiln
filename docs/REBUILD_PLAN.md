# 十月补充申报：kiln 的实质重建

本项目是 DWS-ai-nb/kiln 被退回后在原仓库进行的补充申报，不声称与旧版无关。原始提交保留，旧方程生成器兼容保留；新核心独立放在 `model/`，不导入旧题族、算术或组卷代码。

## 新定位

最终定位为跨字段算术规则的版本回归与最少字段反例库。开发者提交两版变量、离散域和命名约束，得到接受结果改变的具体配置，并相对基线做精确 Hamming 最小化。有限域求解是支撑层；教学选题是模型示例，不再以两种方程或跨语言凭证作为立项价值。

查重发现已有通用有限域求解器、组合测试工具、结构契约反例和网络 ACL 差异库。不能声称它们不存在，也不新增组合覆盖功能；最终独立边界与直接来源见 `docs/ECOSYSTEM.md`。

## 针对驳回意见的变更

| 原问题 | 本次交付与验证 |
| --- | --- |
| 仅支持两种方程 | 无题族枚举的表达式与规则 AST；价格规则、兼容配置、精确选题等独立模型 |
| 验证按题族硬编码 | 独立于搜索的通用赋值检查器；外部 Python 穷举参考解释器核对完整解集 |
| 难度为启发式评分 | 不宣称认知难度；输出实际搜索探测、剪枝、完整性等可测指标 |
| 组卷依赖启发式 | 布尔选取变量、精确配额和禁止组合建模；完整搜索后才宣称无解或最优 |
| 跨语言凭证不足以立项 | 核心价值是可复用规则建模与反例生成；跨语言测试仅为正确性证据 |

## 交付边界

1. 原生 MoonBit 数据模型、受检查整数运算、布尔组合、全异、允许元组和计数约束。
2. 确定性回溯、前向检查、MRV 选变量；支持解数量/工作预算中止，区分穷尽、限解与预算不足。
3. 通用赋值验证、零/一/多解分类、冲突规则删除检查、精确离散最小化。
4. 两版原域并集、接受谓词总化、语义对称差、两版见证回放及精确最少改动字段反例。
5. JSON 解析校验、CLI、可嵌入 API、场景示例、Python 完整解集/差异/最优值对照、CI、文档与 mooncakes 发布。

这不是实数/无限域求解器，也不保证大规模组合模型的性能。可行见证不证明完整解集；无解、唯一和最优结论必须有完整搜索支持。冲突说明只在删除检查均完成时标记为不可再删，不声称最小基数。

## 核验顺序

旧版回归 → 新内核语义与预算测试 → 独立随机穷举解集对照 → 多后端测试 → CLI 示例 → 干净克隆 → mooncakes 消费者 → 公开默认分支 CI。
