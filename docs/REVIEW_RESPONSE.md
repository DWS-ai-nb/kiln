# 对 kiln 初审意见的逐项回应

这是对原项目未通过后的补充修改，不声称与旧版无关，也不将旧提交和旧代码当作本次新增。公开历史基线为 `049b36e`，与找到的本地原版代码树一致。

| 初审指出的问题 | 原版事实 | 本次有效变化与证据 |
| --- | --- | --- |
| 场景价值不明显 | 教学命题价值未形成广泛生态接口 | 主交付改为跨字段算术规则的版本回归库；价格规则、部署兼容、选题配额三组完整模型，每组有 before/after/baseline，可在 CI 中检测变化和回放 |
| 仅两类特定方程 | `Family` 只有二次/分式 | 新 `model/` 不导入 `Family`；算术与布尔 AST、全异、表、计数、受检查整数解释器，可嵌入调用；方程仅是数据模型之一 |
| 验证按题族硬编码 | `verify_item_file` 分派到题族 | 新赋值验证器直接检查原始域和规则；回归见证在两版原始模型上各验证一次；Python 不导入 MoonBit 搜索器，独立核对完整解集与变化集 |
| 难度评估依赖启发式 | 原版加性难度评分 | 不再以认知难度作为新项目承诺；记录探测、节点、剪枝和完整性。最小反例优化的是明确的 Hamming 改动字段数 |
| 组卷依赖启发式 | 贪心不保证有解时找到 | 选题用布尔域、精确配额、互斥约束表示；完整搜索得到可行性/最优性，预算不足单独报告。A 贪心陷阱的示例仍能找到 B/C/E，最小成本 12 |
| 缺乏通用可扩展内核 | DSL 表面通用，底层仅两族 | `regression/` 将两版原域和规则编译为接受集对称差，通用搜索加两版回放；域扩缩、表达式重写、错误算术和配置基线统一处理 |
| 跨语言凭证不足以立项 | 侧重凭证格式 | 不把增加报告格式当新增价值；核心新增为规则语义对比、原域扩缩处理、精确最少字段区分输入。外部解释器仅为正确性证据 |

新内核不是新的通用 CSP 算法发明。已有有限域求解库与本项目底层存在重叠，不能回避，见 [生态比较](ECOSYSTEM.md)。本次选择独立实现小型解释器，是为了让除零/溢出、部分赋值、总化接受和完整性边界在同一个可审核模型中保持一致；不以重写求解器本身作为独立立项价值。

无法由代码决定的事项：赛方是否认定上述补充构成新项目赛道的有效重建、是否通过初审/验收、是否进入优秀项目名单。提交材料应如实写“原申报退回后的实质重建”，不能写成从未开发过的无关新项目。
