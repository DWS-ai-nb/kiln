# kiln · 规则变更回归与最小反例
> AI 辅助技术事实底稿：须由参赛者核实、理解并亲自改写后提交，不能标称为人工原稿。

**参赛者与仓库**：DWS-ai-nb；https://github.com/DWS-ai-nb/kiln 。方向：十月原申报退回后的实质重建，申请新生态项目并争取季度评选；是否按新项目认定以赛方审核为准。Apache-2.0。

**已有基础与新增**：旧版只覆盖二次/分式方程，验证按题族分派，难度与组卷依赖启发式。本次保留公开历史与兼容 API，独立新增有限域算术解释器、完整搜索、两版规则接受集差异、原域扩缩处理、见证回放和最少改动字段优化，不把旧代码量和旧测试计为新增。

**具体问题**：跨字段规则改动后，文字 diff 不能回答“哪些旧配置变得非法”。kiln 接受两版显式有限整数域及约束，输出完整区分输入和命名违规；相对配置基线，精确最小化改动字段数。预算不足返回 unknown，不把未找到当作等价。

**三个可运行场景**：①价格规则增加“应付金额非负”，找到 4 个接受结果变化的输入，最近见证只改 1 个字段；②配置兼容表误删 JS/server 组合，生成受影响配置并回放；③基础题配额从 1 改成 2，在互斥条件下检出原合法选集被拒，并用精确求解/冲突说明定位无解。模型均为原创合成数据，不声称已有生产用户。

**实现路径**：MoonBit AST 支持受检查整数算术、布尔、全异、表和计数；保留各版本原域，在并集域构造接受谓词对称差，使用 MRV/前向检查/回溯搜索，回到两版原模型验证。最近反例以 Hamming 距离为目标，只有穷尽才标记 minimal。边界是有限小模型，不求无限域等价，不做任意程序验证，不将搜索成本当认知难度。

**生态差异**：已有 moonbit_constraint/MoonPlan 的通用求解、EvoWitness 的结构契约反例、MoonPolicyProof 的网络五元组差异、CaseWeave 的组合测试均有价值。本项目聚焦跨字段算术约束版本与相对基线的最少字段反例，不声称生态唯一，不移植上述源码；详细来源与重叠见仓库 ECOSYSTEM/THIRD_PARTY 文档。

**验证与交付**：原版 69 测试保留，新增 37，总计 106；独立 Python 对照 1607 个完整解集、804 对完整差异、270 次最近反例最优值；27 次真实 CLI 退出码检查。交付可嵌入 API、JSON/CLI、三组版本案例、文档及四后端 CI，包为 DWS-ai-nb/kiln@0.2.0；发布及远程 CI 的最终实测结果见随附验收报告。
