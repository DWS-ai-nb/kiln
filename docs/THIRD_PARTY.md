# 来源、许可证与 AI 使用

- 项目 Apache-2.0，根 `LICENSE` 为许可依据，根 `NOTICE` 记录算法来源。
- 新 `model/`、`regression/`、CLI、JS 桥、Python 参考解释器和场景模型为本次独立实现；没有移植生态比较表中项目的源码或测试数据。
- 使用常见的回溯、MRV、前向检查、接受集对称差、Hamming 距离、删除式冲突检查。算法不是本项目发明，也不宣称经过证明助手形式化验证。
- 新纯逻辑包仅使用 `moonbitlang/core`（Apache-2.0）；CLI 读文件与退出使用 `moonbitlang/x@0.5.6`（Apache-2.0）。依赖由 MoonBit 包管理器分发，仓库不复制其实现。
- 旧版 `rng.mbt` 参考 SplitMix64 算法，旧版数学命题的来源说明保留在历史文档与 NOTICE。它们不是新回归功能的依赖。
- Python 对照只使用标准库，Node 适配器只负责加载实际编译的 MoonBit 模块与 JSONL 通信，不实现求解逻辑。
- 全部 fixture 为本项目编写的合成数据；无客户订单、真实部署配置、第三方试题、图片、字体、个人联系方式或来源不明素材。
- AI 辅助了方案调研、编码、测试、调试、文档和技术事实底稿。参赛者需审核来源、理解算法、运行复核并承担维护责任。不得将 AI 技术底稿标称为已满足“人工撰写”的申报书。
